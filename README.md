# Gameflix Three.js Smart TV Receiver

Live Three.js Smart TV Application & Web Companion Dashboard for the Gameflix Mobile Controller.

### 🌐 Live Web App
Open the GitHub Pages app in any Smart TV or Web browser:
👉 **[https://clept0.github.io/Gameflix-TV-Receiver/](https://clept0.github.io/Gameflix-TV-Receiver/)**

### 🎮 Features
- **17-Keypoint AR Humanoid Pose Visualizer (OpCode 0x04)**: Real-time 3D skeleton wireframe with bone cylinders.
- **Air Mouse Motion Pointer (OpCode 0x02)**: Smooth cursor with click indicators and recentering.
- **Virtual Gamepad HUD (OpCode 0x03)**: Real-time analog stick offset and ABXY button lighting.
- **TV Remote Visualizer (OpCode 0x01)**: D-Pad, Navigation, and Media control feedback.
- **Dynamic WebSocket Connector**: Connect to local Wi-Fi endpoints (`192.168.x.x:8080`) or cloud WebSocket relays (`wss://...`).
